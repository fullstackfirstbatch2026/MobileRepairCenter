# Mobile Repair Center

A full-stack mobile phone repair management system built using Java Spring Boot, MySQL, HTML, CSS, JavaScript, and Docker.

## Technologies

- Java 27
- Spring Boot
- Spring Data JPA
- MySQL 8
- HTML
- CSS
- JavaScript
- Docker
- Docker Compose
- Maven

## Features

- Customer management
- Device management
- Technician management
- Repair order management
- Repair status updates
- Automatic repair bill calculation
- Joined repair-order information
- Dashboard statistics
- MySQL stored procedures
- MySQL functions
- MySQL views
- REST APIs
- Dockerized application
